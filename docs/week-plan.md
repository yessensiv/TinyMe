# TinyMe: UI первой недели и план на пять недель

## Основание и изменение ТЗ

Интерфейс подготовлен по прочитанному в начале работы ТЗ 2.0 от 29.10.2026: персональная комната, активное время, монеты, магазин и инвентарь. Во время работы документы в репозитории были заменены коммитом `be269d0` на `docs/tz/TZ.md` с концепцией «Дворец разума» версии 1.1 (задачи, XP, навыки и граф). Эти концепции различаются. Текущий UI относится к первоначально прочитанной концепции комнаты; план ниже относится к ней же. Новое ТЗ не перезаписано. Перед следующей неделей необходимо выбрать актуальную концепцию.

## Неделя 1 — только интерфейс

- `/`: иллюстрация комнаты, пример баланса и таймера, обзор предметов.
- `/shop`: шесть предметов с категориями, размерами и ценами из ТЗ 2.0.
- `/inventory`: стартовые и приобретённые вещи, состояния «В комнате» / «В хранилище».
- Общий layout, адаптивная навигация, карточки, Tailwind CSS, русский интерфейс.
- Работают только переходы. Покупки, фильтры, таймер, редактор и хранение не реализованы; элементы управления отключены, демоданные подписаны.
- Авторизация не включена: исходная концепция предусматривает локальный профиль.

## Остальные недели — ещё не реализованы

| Неделя | Задачи | Проверяемый результат |
|---|---|---|
| 2 | Модель состояния, Context + reducer, локальный профиль, стартовый набор, localStorage, валидация, единственный владелец записи между вкладками | После перезапуска состояние восстанавливается; ошибки не затирают данные |
| 3 | Активное время, монеты, фильтры, подтверждение покупки и отдельные копии | Нет начисления в фоне и повторного списания; покупка сохраняется |
| 4 | PNG-спрайты, сетка 12 × 8, размещение, проверка пересечений, перемещение, уборка | Редактор работает мышью, касанием и клавиатурой |
| 5 | Настройки, оформление, экспорт/импорт, сброс, доступность, итоговые тесты | Проверен полный сценарий и критерии приёмки |

## Небольшая структура

```text
app/                       # три страницы, общий layout и Tailwind
components/navigation/     # навигация и активный маршрут
components/ui/             # заголовок, карточка, иконки и иллюстрации
features/room/             # статичный предпросмотр комнаты
config/demo.ts             # типы представления, каталог и данные макета
```

Корневой `app/` сохранён. Domain/application/infrastructure/state добавляются по мере реализации, пустых слоёв нет. На следующих этапах UI получает данные через props/селекторы вместо демофайла. SVG-сцена — иллюстрация, не редактор сетки. Демобаланс 42 и шесть вещей показывают пример использования; настоящий первый запуск по исходному ТЗ должен начинаться с 0 монет и трёх бесплатных предметов.

## Запуск и границы проверки

`npm ci`, затем `npm run dev`. Маршруты: `/`, `/shop`, `/inventory`.

Production-сборка в текущем окружении остановилась на внутренней ошибке Turbopack при запуске процесса обработки CSS (также вне песочницы). Успешная сборка и визуальная проверка в браузере пока не подтверждены.
