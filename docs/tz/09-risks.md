# 9. Риски

| Риск | Меры |
|---|---|
| Начисление времени в фоне | Проверка visibility/focus, сброс опорной отметки |
| Сон устройства или задержанный тик | Отбрасывание неподтверждённого разрыва более 5 секунд |
| Несколько вкладок дают двойной доход | Эксклюзивная блокировка записи, остальные только читают |
| Повтор подтверждения покупки | Идемпотентный purchaseId и атомарное сохранение |
| Ошибка/quota localStorage | Остановка записи и таймера, сообщение, повтор, экспорт |
| Очистка данных браузера | Понятное описание локального хранения и резервные копии |
| Некорректный импорт | Валидация ссылок, экономики и размещений до замены |
| Потеря последних секунд при сбое | Контрольная запись не реже 5 активных секунд |
| Наложение предметов | Общая доменная проверка footprints для всех способов ввода |
| Неудобное управление на телефоне | Выбор клетки и кнопки вместо обязательного drag-and-drop |
| Бесконечный рост инвентаря и истории | Фильтры, пагинация списков, измерение на проверочном объёме |
| Ручное изменение локального баланса | Признанное ограничение локального MVP; нет платежей и рейтингов |
| Заработок при оставленном открытом окне | Допустим по правилу видимой вкладки с фокусом; нет проверки постоянного ввода |
| Незаметное подталкивание к долгому использованию | Нет streaks, штрафов, наград за непрерывную сессию и обязательных напоминаний |

Локальный MVP не обещает защиту от владельца устройства. Резервная копия восстанавливает снимок, а не добавляет монеты к текущему балансу.
