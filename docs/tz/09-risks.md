## 9. Риски и способы снижения

| Риск | Последствие | Снижение |
|---|---|---|
| Пользователь начисляет XP за формальные действия | Награды теряют смысл | Понятные рекомендации к задачам; отсутствие конкурентного рейтинга |
| Награды выдаются слишком редко | Прогресс кажется незаметным | XP виден после каждого действия; баланс проверяется на пилоте |
| Комната переполняется | Теряется читаемость | Шесть слотов, развитие предметов, отдельная коллекция |
| Граф превращается в плотную сеть | Пользователь не понимает связи | Фокус, фильтры, свёртка, ограничение подписей |
| Потеря localStorage | Потеря истории | Экспорт, предупреждение о локальном хранении, контроль ошибок |
| Повторное нажатие или две вкладки | Двойной XP | Идемпотентность команды, уникальные ограничения, ревизии |
| История показывает текущие значения | Неверное сравнение прошлого | Расчёт по датированным событиям |
| Изменение формулы XP | Непредсказуемый пересчёт | Версия правил и отсутствие молчаливого изменения истории |
| Анимации ухудшают работу мобильного устройства | Медленный интерфейс | Отложенная загрузка, облегчённый режим, остановка симуляции |
| Собственные навыки не имеют иллюстраций | Неполный пользовательский путь | Универсальный предмет и каталог |
| Слишком большой объём SVG-графики | Сдвиг сроков | Утверждение ограниченного каталога до разработки |
