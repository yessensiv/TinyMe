# 8. Этапы разработки и MVP

## Обязательный состав

Один локальный профиль, одна комната 12 × 8, стартовый набор, автоматический таймер, кошелёк с курсом 1 монета за минуту без суточного лимита, каталог из раздела 03, покупка копий, инвентарь, размещение, настройки, автосохранение, экспорт и импорт.

## Порядок реализации

| Этап | Проверяемый результат |
|---|---|
| 1. Данные и правила | Каталог, стартовая комната, экономика, валидатор |
| 2. Сохранение | Создание профиля, восстановление, ошибки, блокировка вкладок |
| 3. Время и монеты | Фокус, пауза, перенос остатка, единственное начисление |
| 4. Магазин и инвентарь | Покупка без двойного списания, отдельные копии |
| 5. Комната | Выбор, предпросмотр, размещение, перемещение и уборка |
| 6. Настройки и перенос | Оформление, экспорт/импорт, сброс |
| 7. Проверка и выпуск | Доступность, адаптивность, интеграционные и e2e-проверки |

Первый сквозной сценарий: активное время → монеты → покупка → инвентарь → размещение → перезапуск.

Иллюстрации и анимации добавляются после проверки этого пути. Календарная оценка уточняется после подготовки спрайтов и проверки редактора; оценка 27–38 дней из старой концепции к этому ТЗ не применяется.

## Условие выпуска

Выполнены критерии раздела 10, нет блокирующих дефектов экономики и сохранения, основной путь проверен на мобильном и настольном экранах.
