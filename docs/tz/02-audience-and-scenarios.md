# 2. Аудитория и пользовательские сценарии

## Аудитория

Пользователи, которым нравится пиксельная эстетика, оформление интерьеров и спокойные персональные пространства. Приложение не требует вести список дел или подтверждать жизненные достижения.

## Сценарии

| ID | Сценарий |
|---|---|
| US-01 | Открыть готовую базовую комнату без регистрации |
| US-02 | Указать имя и ознакомиться с правилами монет |
| US-03 | Видеть время посещения, баланс и отсчёт до монеты |
| US-04 | Найти предмет по категории и посмотреть цену |
| US-05 | Купить предмет при достаточном балансе |
| US-06 | Выбрать купленную копию в инвентаре |
| US-07 | Разместить, переместить или убрать предмет |
| US-08 | Выбрать оформление стен и пола |
| US-09 | Закрыть приложение и продолжить позже |
| US-10 | Экспортировать или восстановить резервную копию |

## Основной путь

1. При первом запуске создаются профиль, комната и стартовые предметы.
2. Пользователь видит баланс 0 и краткое объяснение экономики.
3. Видимая вкладка с фокусом учитывает активное время.
4. Через 60 активных секунд начисляется 1 монета.
5. После накопления цены пользователь подтверждает покупку.
6. Предмет появляется в инвентаре и доступен для размещения.
7. Пользователь выбирает свободную позицию на сетке.
8. Изменение сохраняется; после перезагрузки комната восстанавливается.

## Исключения

- Не хватает монет: покупка недоступна, показана недостающая сумма.
- Нет места: предмет остаётся в инвентаре, предложено освободить клетки.
- Потеря фокуса: таймер приостановлен с понятной причиной.
- Другая вкладка владеет хранилищем: показан режим чтения.
- Ошибка сохранения: действие не считается успешным; доступен повтор.
