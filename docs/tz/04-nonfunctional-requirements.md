# 4. Нефункциональные требования

## Интерфейс и доступность

- Поддержка экранов от 360 px; основные страницы без горизонтального переполнения.
- Комната масштабируется в своей области с сохранением сетки и чёткости пикселей.
- Все операции покупки и размещения доступны без перетаскивания, с клавиатуры и касанием.
- Видимый фокус, доступные названия, текстовые причины ошибок; цвет не является единственным индикатором.
- Целевой уровень доступности интерфейса — WCAG 2.2 AA.
- Системный prefers-reduced-motion учитывается; сложные анимации отключаются.
- Звук выключен по умолчанию, воспроизведение включается действием пользователя.

## Производительность

| Показатель | Цель |
|---|---|
| LCP главного экрана | ≤ 2,5 с в согласованном тестовом окружении |
| Отклик выбора предмета | ≤ 100 мс |
| Покупка и размещение с сохранением | ≤ 300 мс на тестовом устройстве |
| Проверочный объём | 500 копий в инвентаре, 5000 покупок, до 96 размещений |
| Анимации | Цель 60 FPS; возможность уменьшить эффекты |

Перед выпуском фиксируются устройство, браузер, сеть и набор данных для воспроизводимых измерений. Во время паузы нет фонового начисления. Полный интерфейс не перерисовывается каждую миллисекунду.

## Надёжность и приватность

- Все денежные изменения и связанные сущности сохраняются целостным снимком.
- Схема версионируется, данные проверяются при чтении и импорте.
- При ошибке записи сохраняется последнее подтверждённое состояние, таймер останавливается до восстановления записи.
- Повреждённые данные сохраняются для восстановления.
- Пользовательские строки выводятся как текст.
- В MVP данные профиля не отправляются на сервер, аналитика не обязательна.
- Объясняется, что очистка данных браузера удаляет локальное состояние; предлагается экспорт.
- Предельные значения счётчиков проверяются на безопасное целочисленное представление; суточного ограничения заработка нет.

## Совместимость

Проверяются текущая и предыдущая основные версии Chrome, Edge, Firefox и Safari на момент выпуска, включая мобильные Chrome и Safari. Возможности блокировок и хранилища определяются при запуске. При их недоступности показывается объяснение вместо небезопасного начисления.
