# 11. Развитие после MVP

Имя файла сохранено для стабильности ссылок. Этот раздел описывает будущие версии приложения; актуальная версия самого ТЗ — 2.0.

| Направление | Возможности |
|---|---|
| Аккаунты | Регистрация и перенос гостевого профиля |
| Облако | Синхронизация устройств и резервные копии |
| Интерьер | Дополнительные комнаты, расширение сетки, вращение |
| Каталог | Новые коллекции, настенные предметы и размещение на мебели |
| Персонализация | Персонаж в комнате, дополнительные темы и эффекты |
| Друзья | Взаимные приглашения и просмотр комнат только с разрешения владельца |
| Платформы | Устанавливаемая PWA или отдельное настольное приложение |

Просмотр комнаты друга — только чтение, по умолчанию выключен, доступ можно отозвать. Добавление облака требует отдельной модели доступа и разрешения конфликтов.

Эти функции не обязательны для первого выпуска. Они не меняют базовую экономику: 1 монета за активную минуту, без суточного лимита и штрафов за перерыв. Офлайн-начисление, реальные платежи, XP, уровни и обязательные задачи не планируются в рамках этого ТЗ.
