## 11. Идеи для версии 2.0

| Направление | Возможности |
|---|---|
| Аккаунт | Авторизация, Supabase, синхронизация устройств |
| Планирование | Повторяющиеся задачи, расписание, мягкие напоминания |
| Комната | Расстановка предметов, дополнительные пространства и темы |
| Граф | Типизированные связи, ручное связывание, сохранённые представления |
| Подтверждение действий | Импорт активности из учебных и спортивных сервисов |
| Аналитика | Недельные отчёты, распределение времени, динамика навыков |
| Персонализация | Дополнительные комплекты и тематические каталоги наград |
| Совместная работа | Добровольный обмен достижениями, общие учебные цели |
| Доступность | Дополнительные режимы контраста и упрощённая навигация |
| Мобильное использование | Устанавливаемая PWA и расширенный офлайн-режим |

Для следующих версий сохраняются базовые принципы: отсутствие штрафов за перерывы, награды за действия, единый источник данных и возможность пользоваться продуктом без публичного сравнения с другими.
