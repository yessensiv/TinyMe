# Техническое задание: TinyMe — персональная пиксельная комната

**Версия документа:** 2.0  
**Дата:** 29 октября 2026 года  
**Тип продукта:** персональное веб-приложение.  
**Название:** TinyMe; MyRoom — ранее использованное название этой концепции.

## Назначение документа

Документ заменяет ТЗ версии 1.0 о задачах, навыках, XP и графе достижений. Все разделы 00–11 описывают единую актуальную концепцию: комнату, активное время, монеты, магазин и инвентарь. Номер версии документа не означает, что приложение уже реализовано.

## Зафиксированные требования пользователя

- Персональная интерактивная пиксельная комната.
- Автоматический учёт времени активного использования приложения.
- 1 монета за минуту, без суточного лимита.
- Магазин, инвентарь, сохранение и восстановление данных.
- Без обязательных задач, RPG-прокачки и графа достижений.

## Принятые решения для MVP

| Вопрос | Решение |
|---|---|
| Платформа | Веб-приложение, один локальный профиль |
| Язык | Русский |
| Активность | Видимая вкладка и окно с фокусом; ввод с клавиатуры и мыши не обязателен |
| Фон и офлайн | Время не начисляется |
| Сон устройства | Интервал сна исключается; после пробуждения отсчёт начинается заново |
| Неполная минута | Подтверждённый остаток сохраняется между посещениями |
| Несколько вкладок | Единственный владелец таймера и записи; остальные читают состояние |
| Начало | 0 монет, базовая комната, бесплатный стартовый набор |
| Предметы | Покупка отдельных копий; каждая размещается один раз |
| Редактор | Прямоугольная сетка пола 12 × 8, без вращения в MVP |
| Хранение | localStorage и резервная копия JSON |
| Продажа и возврат | Отсутствуют в MVP |
| Реальные деньги | Покупка, вывод и переводы монет отсутствуют |

Это спецификация поведения первой реализации. Уточнение ассортимента и иллюстраций допускается без изменения правил экономики. Начальный каталог и цены заданы в разделе 03.
