# Техническое задание: TinyMe — «Дворец разума»

**Версия:** 1.0  
**Дата:** 22 октября 2026 года  
**Тип продукта:** персональное веб-приложение для визуализации прогресса.  
**Рабочее название:** TinyMe. «Дворец разума» — название внутреннего пространства пользователя.

Приложение превращает реальные действия пользователя в видимые изменения: растут навыки, открываются элементы внешности аватара, комната наполняется предметами, формируется граф достижений.

## Допущения и открытые вопросы

Ниже приведены **предлагаемые решения для MVP, требующие согласования перед разработкой**.

| Вопрос | Допущение для MVP |
|---|---|
| Авторизация | Отсутствует. Один локальный профиль в одном браузере |
| Подтверждение действий | Пользователь самостоятельно отмечает выполнение. Проверка достоверности не предусмотрена |
| Язык | Русский. Структура интерфейса допускает последующую локализацию |
| Три слоя кастомизации | Причёска, одежда, аксессуар. Цвет кожи и волос задаются отдельно |
| Темы | По две независимые темы: комната — «Уютная» и «Киберпанк»; граф — «Obsidian» и «Белая доска» |
| Трёхмерная сцена | Не используется. Аватар и комната реализованы через слоистый SVG |
| Пять–шесть предметов | Шесть типов предметов и не более шести одновременно размещённых объектов |
| Выдача предметов | При достижении уровней 3, 6, 9 и далее **в каждом навыке** |
| Начальный уровень | Уровень 1, 0 XP |
| Начисление XP | По фиксированной сложности задачи: 10 / 25 / 50 XP |
| Повторяющиеся задачи | В MVP отсутствуют. Пользователь может вручную создать аналогичную задачу |
| Исторический просмотр | Отражает зарегистрированные события, без ручного добавления достижений задним числом |
| Часы и книги | Время вводится вручную при завершении задачи; книга учитывается через специальный тип задачи |
| Сроки разработки | План ниже является ориентиром; оценка уточняется после утверждения макетов |

**До разработки необходимо согласовать:** формулу уровней, каталог наград, соответствие предметов навыкам, правила исправления ошибочно отмеченных задач и окончательный состав MVP.
