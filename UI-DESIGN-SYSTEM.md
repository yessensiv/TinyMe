# MyRoom · Cozy dark UI

Общий визуальный контракт находится в `src/app/cozy.css`, подключённом после базовых стилей и компоновки. Для новых контролов используйте эти токены и варианты вместо отдельной палитры экрана. Изометрический рендерер и цвета пользовательской мебели в этот контракт не входят.

| Элемент | Правило |
| --- | --- |
| Основной фон | `--ui-bg: #16141c` |
| Текст / вторичный текст | `#f4f4f5` / `#a1a1aa` |
| Поверхность карточки | Белый 3%, обводка белый 7%, радиус 16 px |
| Primary | Кремовый `#f3e9dc`, текст `#09090b`, hover `#e5d7c6` |
| Secondary | Белый 4%, hover 8%, обводка 10%, текст `#e4e4e7` |
| Disabled | Белый 2%, обводка 5%, текст `#71717a`, запрещающий курсор |
| Контролы | Радиус 12 px; круглая форма только у вкладок основного меню на широком экране |
| Заголовок страницы H1 | Cormorant Garamond |
| Остальной интерфейс | Inter, затем Segoe UI / sans-serif |
| Числа | `.tabular-nums`, выравнивание значения и единицы по baseline |
| Размер предмета | `.size-badge`, моноширинный 11 px; остальные бейджи — sans-serif |
| Иконки | Lucide, strokeWidth 1.75, 16 px; плеер и настройки — 20 px |
| Плеер | Zinc 900 / 85%, blur 24 px, граница 10%, тёмная тень |
| Ползунки | Дорожка 4 px, лавандовый акцент, thumb 10 px |

Основной контейнер имеет `.pb-32` с запасом 144 px на широком экране и 224 px на мобильном, плюс safe-area. Такой же запас используется в `scroll-padding-bottom`, чтобы при прокрутке к фокусу контент оставался выше плеера и меню.

Функциональные границы: изменения ограничены стилями, классами, размерами иконок и оформлением числовых значений. Обработчики событий, React hooks, состояние, доменная логика, сохранение, экономика, аудио и геометрия комнаты не меняются.

## Уведомления

`NotificationCenter` и `notifications.css`: тёмное матовое стекло, радиус 16 px, тонкая граница, иконка мебели с лавандовой подложкой либо монета с тёплой подложкой. Стек расположен над плеером: снизу 132 px на широком экране, 200 px на мобильном плюс safe area. Одновременно показаны два сообщения, остальные ожидают в очереди. Успешные покупки и награды отображаются 5 секунд, общие сообщения — 7 секунд. Наведение и фокус приостанавливают автозакрытие; после ухода отсчёт начинается заново. Кнопка закрытия доступна с клавиатуры, сообщения объявляются через polite status.

Появление — 280 мс с небольшим подъёмом, исчезновение — 220 мс. Удаление из очереди не зависит от события CSS-анимации; reduced motion отключает движение. Сами уведомления не начисляют монеты и не изменяют данные комнаты: покупки публикуются после успешной команды, награды наблюдают подтверждённые полные минуты и пропускают первичную загрузку и смену аккаунта.

## Переходы интерфейса

Звуковой отклик уведомлений: покупка — мягкий аккорд, монеты — два тихих тона; длительность до 0.7 секунды, сглаженная атака и затухание. В настройках есть общий выключатель и отдельные переключатели покупок и начисления монет с кнопками примера. Звон монет по умолчанию выключен; прежний общий выбор сохраняется. Выключение общего звука не сбрасывает отдельные предпочтения. Настройки хранятся на устройстве, визуальные уведомления остаются. Общие сообщения без звука. Сигналы не повторяются из очереди уведомлений и не проигрываются в скрытой вкладке; они не входят в музыкальную статистику.

`src/app/motion.css` подключён последним. Общая кривая `cubic-bezier(.22,1,.36,1)` даёт мягкое замедление без пружин и отскоков. Нажатие — 110 мс, контролы — 180 мс, поверхности и панели — 240 мс, вход вкладки — 280 мс. Контент проявляется, заголовок смещается на 6 px; повторные обновления таймеров не перезапускают анимацию. Разные имена анимации для вкладок позволяют повторять переход без перемонтирования компонентов и задержки действий. Плеер и меню остаются неподвижными.

При наведении мыши кнопки поднимаются на 1 px, карточки предметов — на 3 px с мягкой тенью; основные действия получают слабое тёплое свечение. Остальные карточки меняют только поверхность и границу. Нажатие уменьшает активную кнопку до 97%; недоступные кнопки неподвижны. На сенсорных экранах остаётся только отклик на нажатие. `prefers-reduced-motion: reduce` отключает декоративное движение и переходы. Предки изометрической комнаты не получают transform/translate, поэтому координаты перетаскивания и развёрнутый режим сохраняются.
